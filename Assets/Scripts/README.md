# Skripte igre – gde je šta

| Folder | Šta sadrži |
| --- | --- |
| `Core` | Osnova koju koristi sve: tasteri (Keybinds), džojstik i dodir, podešavanja, kamera, sprajtovi iz koda, glatki zidovi, varijante pločica |
| `Audio` | Zvučni efekti (Sfx) i muzika (GameAudio) |
| `Save` | Čuvanje i nastavak partije (SaveSystem) |
| `Player` | Lik: kretanje, borba, zdravlje, mana, oprema, oružja, napici, nivoi |
| `Player/Skills` | Stablo veština i efekti veština u borbi |
| `Player/Look` | Izgled lika, animacija tela i ljubimac |
| `Combat` | Projektili, šteta, čarolije, munja, otrov, eksplozije |
| `Weapons` | Podaci o oružjima, katalog i retkost |
| `Items` | Predmeti, rune, jedinstveni predmeti, kovčezi i plen |
| `Enemies` | Zdravlje, nivo, usporavanje, kretanje i ponašanje protivnika |
| `Enemies/Bosses` | Susret sa bossom i četiri bossa |
| `Enemies/Variants` | Posebne osobine (iscelitelj, senka, ledena aura, nestabilni) i elitni protivnici |
| `Levels` | Nivoi i sve u njima: vrata, poluga, kapije, zamke, beleške, oltari, kamp, tama hrama |
| `Interaction` | Interakcija igrača sa svetom (taster E) |
| `Modes` | Endless, dnevni izazov, ugovori i rang lista |
| `UI` | Pravljenje elemenata interfejsa (UiFactory) i pomoćni efekti |
| `UI/HUD` | Sve što se vidi tokom igre: trake, mapa, hotbar, brojevi štete, kontrole na dodir |
| `UI/Menus` | Prozori: glavni meni, inventar, kamp, lik, stablo veština, podešavanja |

Alati za pravljenje sadržaja (rade samo u Unity editoru) su u `Assets/Editor`.
